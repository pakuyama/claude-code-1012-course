Claude Code로 하루 만에 만든 4가지 프로젝트

데이터 수집, 교육 자료 제작, 웹앱 배포, 도구 확장까지. 2026년 10월 12일 하루 동안 Claude Code와 함께 실제로 진행한 작업을 그대로 따라 할 수 있게 정리한 강의입니다.

  • 총 4강
  • 강의당 15~25분
  • 난이도: 입문~중급
  • 환경: Windows 11
이 강의를 마치면
  • 웹사이트의 숨은 API를 찾아 데이터를 모으고 대시보드로 시각화할 수 있습니다.
  • 원고와 디자인을 분리한 파이프라인으로 그림 많은 PPT 강의자료를 자동 생성할 수 있습니다.
  • 계획서 작성부터 GitHub Pages 배포까지 웹앱 하나를 끝까지 완성할 수 있습니다.
  • 외부 스킬 저장소에서 필요한 스킬만 골라 프로젝트에 설치할 수 있습니다.

네 강의를 관통하는 원칙

  1. 먼저 계획하고, 결과를 확인하며 넓혀 간다. 네 프로젝트 모두 "계획 → 작은 맛보기 → 전체 확장" 순서로 진행했습니다.
  2. "됐다"고 믿지 말고 눈으로 확인한다. 샘플 검수, 슬라이드 PNG 렌더, 배포 사이트 curl 확인 등 매번 결과를 직접 검증했습니다.
  3. 사람이 결정할 일은 사람에게 묻는다. 약관 동의, 다운로드 권한, 파일 삭제처럼 되돌리기 어려운 일은 Claude가 묻고 사람이 결정했습니다.
  4. 한글 Windows의 함정을 기억한다. cp949 인코딩 오류, PowerShell 실행 정책, 긴 heredoc 파싱 오류는 네 프로젝트에서 반복해서 나왔습니다.
