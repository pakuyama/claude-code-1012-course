AI로 한글(HWP) 파일을 수정하는 스킬 설치하기

공문서, 신청서, 양식은 대부분 한글(.hwp) 파일입니다. 그런데 Claude는 기본 상태로는 HWP를 읽거나 고칠 수 없습니다. 이번 강의에서는 k-skill 저장소에서 HWP 관련 스킬을 골라 설치해 "이 한글 파일 고쳐줘"가 통하는 프로젝트를 만듭니다.

  • 소요 시간: 약 20분
  • 설치 스킬: 4개 (HWP 3개 + WHOIS 1개)
  • 범위: 프로젝트 스코프
  • 필요: Node.js 18+
학습 목표
  • 왜 HWP 수정에 스킬이 필요한지 이해합니다.
  • HWP 스킬 3개(읽기·편집·디버깅)의 역할을 구분합니다.
  • 스킬을 이 프로젝트에만 설치하고, 필요 없는 스킬을 정리합니다.
  • 설치한 스킬로 한글 파일을 수정하는 프롬프트를 써 봅니다.
목차
  1. 왜 스킬이 필요한가
  2. HWP 스킬 3총사

  6. 정리와 퀴즈

1. 왜 스킬이 필요한가

HWP는 한컴오피스 전용 바이너리 형식이라, 텍스트 파일처럼 열어서 고칠 수 없습니다. Claude가 한글 파일을 다루려면 HWP를 읽고 쓰는 도구와 그 도구를 언제, 어떻게 쓰는지에 대한 설명서가 필요합니다. 이 설명서 묶음이 스킬입니다.

스킬은 SKILL.md 파일이 들어 있는 폴더입니다. 맨 위의 이름과 설명을 보고 Claude가 상황에 맞는 스킬을 골라 씁니다.

---
name: rhwp-edit
description: Edit HWP documents — insert/delete text, replace-all,
             create tables, set cell text — with the k-skill-rhwp CLI ...
---

2. HWP 스킬 3총사

k-skill의 "🛠️ 개발자·문서 도구" 묶음에는 HWP 스킬이 세 개 있습니다. 역할이 겹치지 않게 나뉘어 있어서, Claude가 작업에 따라 알맞은 것을 고릅니다.

스킬역할이럴 때엔진
hwp읽기·변환HWP 내용을 Markdown/JSON으로 뽑기, 두 문서 비교, 양식 필드 추출, Markdown → HWPX 생성kordoc
rhwp-edit편집본문에 글 넣기·지우기, 서식 유지한 채 일괄 치환, 표 만들기, 표 셀 채우기k-skill-rhwp (@rhwp/core WASM)
rhwp-advanced고급 진단레이아웃 깨짐 디버깅, 내부 구조 덤프, 버전 비교, 썸네일, 배포용 문서 잠금 해제rhwp Rust CLI

같은 묶음에 있던 kr-whois-lookup(.kr 도메인 등록정보 조회)도 함께 설치했지만, 이번 강의의 주인공은 HWP 스킬 세 개입니다.

팁: 읽기는 hwp, 고치기는 rhwp-edit

"이 문서 요약해줘", "양식에 뭘 채워야 해?"는 hwp가, "날짜를 바꿔줘", "표에 이름 채워줘"는 rhwp-edit가 맡습니다. 보통은 hwp로 내용을 파악한 뒤 rhwp-edit로 고치는 순서가 됩니다.

3. 프로젝트에 설치하기

https://github.com/NomaDamas/k-skill 여기서 개발자·문서 도구 스킬들만 내 프로젝트 스코프로 설치해줘

설치 범위위치적용 대상
전역 (-g)~/.claude/skills/내 모든 프로젝트
프로젝트<프로젝트>/.claude/skills/그 폴더에서 연 세션만

한글 문서 작업용 폴더에서만 HWP 스킬이 켜지도록 프로젝트 스코프를 골랐습니다. 공식 설치 명령은 npx skills이고, README 예시의 -g를 빼면 프로젝트에 설치됩니다.

# 한글 문서 작업 폴더에서
npx --yes skills add NomaDamas/k-skill --skill hwp
npx --yes skills add NomaDamas/k-skill --skill rhwp-edit
npx --yes skills add NomaDamas/k-skill --skill rhwp-advanced
npx --yes skills add NomaDamas/k-skill --skill kr-whois-lookup
실제로 있었던 일: Node.js가 없었다

처음에는 npx가 없어서 Claude가 스킬 폴더를 .claude/skills/에 직접 복사하는 수동 설치로 우회했습니다. 하지만 HWP 스킬은 실행할 때 npx로 kordoc, k-skill-rhwp를 불러오기 때문에 Node.js가 꼭 필요합니다. 이후 winget install OpenJS.NodeJS.LTS로 Node.js를 설치했고, 이때 --all로 실행하는 바람에 131개 스킬이 모두 설치됐습니다.

4. 필요 없는 스킬 정리하기

나머지 지워줘

삭제하기 전에 Claude는 설치 구조부터 확인했습니다. npx skills는 한 곳에만 설치하지 않았습니다.

.agents/skills/       스킬 원본
.claude/skills/       원본을 가리키는 심볼릭 링크
agent/skills/         별도 복사본
skills-lock.json      설치 목록과 해시
  1. 세 폴더 모두에서 4개를 제외한 127개를 삭제했습니다.
  2. skills-lock.json에서도 지운 항목을 빼서 4개만 남겼습니다.
  3. .claude/skills의 링크가 원본과 제대로 연결돼 있는지 확인했습니다.
팁: 스킬은 많을수록 좋은 게 아니다

맛집, 주식, 버스 예매 스킬이 함께 있으면 Claude가 매번 읽어야 할 설명이 늘고, 엉뚱한 스킬을 고를 가능성도 커집니다. 한글 문서 작업 폴더에는 문서 스킬만 두세요.

주의: 지우기 전에 확인하기

131개 설치를 처음 발견했을 때 Claude는 바로 지우지 않았습니다. 사용자가 직접 설치한 파일이었기 때문에 먼저 상황을 보고하고 "나머지 지워줘"라는 확인을 받은 뒤에 삭제했습니다.

5. 실전: 한글 파일 고치기

설치를 마쳤으면 새 세션을 열고, 고칠 HWP 파일을 프로젝트 폴더에 넣은 뒤 평소 말투로 요청하면 됩니다.

이렇게 요청해 보세요

신청서.hwp 내용을 읽고 어떤 항목을 채워야 하는지 정리해줘

신청서.hwp에서 서식은 그대로 두고 2025를 전부 2026으로 바꿔줘

신청서.hwp 첫 번째 표의 대표자 칸에 '홍길동'을 넣어줘

보고서.hwp 맨 앞에 제목 한 줄 넣고, 3행 4열짜리 빈 표를 추가해줘

Claude가 내부에서 하는 일

rhwp-edit 스킬은 대략 이런 순서로 동작합니다. 직접 명령을 칠 필요는 없지만, 흐름을 알아 두면 결과를 확인하기 쉽습니다.

  1. 구조 파악: 섹션, 문단 수와 길이를 확인합니다. 
    npx k-skill-rhwp info 신청서.hwp
  2. 위치 찾기: 바꿀 글자가 어디 있는지 검색합니다. 
    npx k-skill-rhwp search 신청서.hwp --query 2025
  3. 편집: 결과는 항상 새 파일로 저장합니다. 원본은 덮어쓰지 않습니다. 
    npx k-skill-rhwp replace-all 신청서.hwp ./out/신청서_2026.hwp \
  --query 2025 --replacement 2026
  4. 확인: 페이지를 SVG로 렌더하거나 hwp 스킬로 다시 읽어 바뀐 내용을 검증합니다. 
    npx k-skill-rhwp render ./out/신청서_2026.hwp --page 1 --format svg
알아 둘 한계
  • 저장 형식: .hwpx를 넣어도 편집 결과는 .hwp(HWP 5.x)로 저장됩니다. HWPX가 꼭 필요하면 hwp 스킬의 Markdown → HWPX 변환을 씁니다.
  • 일괄 치환 범위: replace-all은 본문 문단만 바꿉니다. 표 안의 글자는 셀을 지정해 set-cell-text로 고칩니다.
  • 한컴오피스 조작은 안 됨: 파일 형식을 직접 다루는 도구라서, 한글 프로그램을 띄워 클릭하거나 보안 모듈을 통과하는 일은 하지 않습니다.
  • 최종 확인은 사람이: 제출용 문서는 한컴오피스로 열어 서식이 의도대로인지 꼭 확인하세요.

6. 정리

핵심 요약
  1. Claude가 HWP를 다루려면 스킬이 필요합니다. 읽기는 hwp, 편집은 rhwp-edit, 진단은 rhwp-advanced입니다.
  2. -g를 빼면 프로젝트 스코프로 설치됩니다. 한글 작업 폴더에만 설치하세요.
  3. HWP 스킬은 npx로 동작하므로 Node.js 18 이상이 필요합니다.
  4. 설치 도구가 여러 위치와 잠금 파일을 만들 수 있으니, 정리할 때는 모두 확인합니다.
  5. 편집 결과는 항상 새 파일로 저장되고, 제출 전 최종 확인은 사람이 합니다.

확인 퀴즈

Q1. "보고서.hwp 내용 요약해줘"에는 어떤 스킬이 쓰일까요?

hwp 스킬입니다. kordoc으로 HWP를 Markdown으로 변환해 읽습니다.

Q2. 표 안의 "2025"가 일괄 치환으로 안 바뀌었습니다. 왜 그럴까요?

replace-all은 본문 문단만 바꾸기 때문입니다. 표 셀은 set-cell-text로 셀을 지정해 고쳐야 합니다.

Q3. 전역 설치와 프로젝트 설치를 가르는 옵션은?

-g입니다. 붙이면 ~/.claude/skills에, 빼면 현재 프로젝트의 .claude/skills에 설치됩니다.

Q4. .claude/skills만 지우면 정리가 끝날까요?

아니요. 그 안은 링크일 뿐이고, 원본(.agents/skills), 복사본(agent/skills), skills-lock.json도 함께 정리해야 합니다.

실습 과제

최근에 받은 한글 양식 하나를 프로젝트 폴더에 넣고 "이 양식에서 채워야 할 칸을 표로 정리하고, 내가 불러주는 내용으로 채워서 새 파일로 저장해줘"라고 요청해 보세요.
