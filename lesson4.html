4강 · 프로젝트 10.12(4)

외부 스킬 저장소에서 필요한 스킬만 프로젝트에 설치하기

스킬은 Claude Code에 새 능력을 더해 주는 확장 묶음입니다. 한국 서비스용 스킬 130여 개가 담긴 k-skill에서 개발자·문서 도구 4개만 골라 이 프로젝트에만 설치해 봅니다.

  • 소요 시간: 약 20분
  • 최종 설치: 스킬 4개
  • 범위: 프로젝트 스코프
학습 목표
  • 스킬이 무엇이고 어디에 설치되는지 압니다.
  • 전역(-g) 설치와 프로젝트 스코프 설치의 차이를 이해합니다.
  • 필요한 스킬만 남기고 정리하는 방법을 익힙니다.

1. 스킬이란?

스킬은 SKILL.md 파일이 들어 있는 폴더입니다. 파일 맨 위에 이름(name)과 설명(description)이 있고, Claude는 이 설명을 보고 상황에 맞는 스킬을 골라 씁니다.

---
name: hwp
description: Use kordoc for agent-native HWP/HWPX document parsing, ...
---
(사용법, 명령어, 주의사항 ...)
설치 범위위치적용 대상
전역 (-g)~/.claude/skills/내 모든 프로젝트
프로젝트<프로젝트>/.claude/skills/그 폴더에서 연 세션만

2. 요청과 스킬 고르기

https://github.com/NomaDamas/k-skill 여기서 개발자·문서 도구 스킬들만 내 프로젝트 스코프로 설치해줘

Claude는 저장소를 내려받아 README의 "🛠️ 개발자·문서 도구" 표에서 대상 스킬을 찾았습니다.

스킬용도
hwpHWP/HWPX를 Markdown/JSON으로 변환, 문서 비교, 양식 필드 추출
rhwp-editHWP 본문 텍스트 수정, 표 생성, 셀 편집
rhwp-advancedHWP 레이아웃 디버깅, 내부 구조 덤프, 썸네일 추출
kr-whois-lookup.kr/.한국 도메인, IP 등록정보 조회

3. 설치 방법

공식 설치 명령은 npx skills입니다. README 예시에는 전역 설치용 -g가 붙어 있으니, 프로젝트에 설치하려면 -g를 빼고 프로젝트 폴더에서 실행합니다.

# 프로젝트 폴더에서, 필요한 스킬만
npx --yes skills add NomaDamas/k-skill --skill hwp
npx --yes skills add NomaDamas/k-skill --skill rhwp-edit
npx --yes skills add NomaDamas/k-skill --skill rhwp-advanced
npx --yes skills add NomaDamas/k-skill --skill kr-whois-lookup
실제로 있었던 일: Node.js가 없었다

처음 세션에서는 npx를 찾을 수 없어서, Claude는 스킬 폴더를 .claude/skills/에 직접 복사하는 수동 설치로 우회했습니다. 이후 다른 세션에서 winget install OpenJS.NodeJS.LTS로 Node.js를 설치하고 --all로 전체를 설치하는 바람에 131개가 모두 들어왔습니다.

4. 필요 없는 스킬 정리하기

나머지 지워줘

삭제하기 전에 Claude는 설치 구조부터 확인했습니다. npx skills는 한 곳에만 설치하지 않았습니다.

.agents/skills/       스킬 원본
.claude/skills/       원본을 가리키는 심볼릭 링크
agent/skills/         별도 복사본
skills-lock.json      설치 목록과 해시
  1. 세 폴더 모두에서 4개를 제외한 127개를 삭제했습니다.
  2. skills-lock.json에서도 지운 항목을 빼서 4개만 남겼습니다.
  3. .claude/skills의 링크가 원본과 제대로 연결돼 있는지 확인했습니다.
팁: 스킬은 많을수록 좋은 게 아니다

스킬이 많으면 Claude가 매번 읽어야 할 설명이 늘고, 비슷한 스킬 중 엉뚱한 것을 고를 가능성도 커집니다. 프로젝트에 필요한 것만 두세요. k-skill에는 사용 통계로 안 쓰는 스킬을 찾아주는 k-skill-cleaner도 있습니다.

주의: 지우기 전에 확인하기

131개 설치를 처음 발견했을 때 Claude는 바로 지우지 않았습니다. 사용자가 직접 설치한 파일이었기 때문에 먼저 상황을 보고하고 "나머지 지워줘"라는 확인을 받은 뒤에 삭제했습니다.

5. 정리

핵심 요약
  1. 스킬은 SKILL.md가 든 폴더이고, 설명을 보고 Claude가 골라 씁니다.
  2. -g를 빼면 프로젝트 스코프로 설치됩니다.
  3. 설치 도구가 여러 위치와 잠금 파일을 만들 수 있으니, 정리할 때는 모두 확인합니다.
  4. 되돌리기 어려운 삭제는 확인을 받고 진행합니다.

확인 퀴즈

Q1. 전역 설치와 프로젝트 설치를 가르는 옵션은?

-g입니다. 붙이면 ~/.claude/skills에, 빼면 현재 프로젝트의 .claude/skills에 설치됩니다.

Q2. .claude/skills만 지우면 정리가 끝날까요?

아니요. 그 안은 링크일 뿐이고, 원본(.agents/skills), 복사본(agent/skills), skills-lock.json도 함께 정리해야 합니다.

마무리

오늘 네 프로젝트의 공통점은 짧은 요청, 계획 먼저, 결과 확인, 중요한 결정은 사람이 내린다는 것이었습니다. 여러분의 프로젝트에서도 이 네 가지를 기억해 보세요.
